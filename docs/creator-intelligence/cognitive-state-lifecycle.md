# Creator Cognitive State Lifecycle

## Purpose

Strategic planning should reason over creator evolution, not isolated videos. `CreatorCognitiveState` summarizes novelty, fatigue, resonance, identity drift, audience alignment, and stability.

## Lifecycle

1. Observable packets provide objective signals.
2. Interpretive packets map observations to ontology labels.
3. Identity vectors and drift reports update slow-moving identity state.
4. Experiments and feedback adjust resonance and alignment.
5. Temporal weighting decays stale trend and audience signals.

## Guardrails

- Cognitive state is a derived snapshot, not source truth.
- Each metric links back to provenance.
- Low-confidence states cannot drive high-confidence recommendations.
